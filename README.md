# Congregation Field Service Group Kit

회중 야외 봉사 집단 운영을 돕는 웹 프로그램 배포본입니다.

성원은 자기 집단 화면에서 온라인 봉사 보고, 임명 확인, 회중 광고, 집단 편성표를 봅니다. 집단 감독자·보조자와 회중 역할자는 PIN 으로 로그인해 권한에 맞는 편집 메뉴를 씁니다. 휴대폰에서는 "홈 화면에 추가"로 앱처럼 설치됩니다.

---

## 처음 설치하는 분은 여기부터

컴퓨터에 미리 설치할 프로그램은 없습니다. 설치 파일을 두 번 클릭하면 **설치 도우미**가 화면으로 안내합니다.

1. ZIP 을 `문서` 폴더 등에 풀기
2. **Windows: `설치.cmd`** / **Mac: `설치.command`** 두 번 클릭
3. 화면 순서대로: 회중 정보 입력 → Google 로그인 → (Firebase 콘솔에서 "시작하기" 한 번) → Cloudflare 로그인 → [설치 시작]
4. 완료 화면의 접속 주소를 성원에게 공유, 편집자 로그인 후 **기본 PIN 변경**

보통 10~15분 걸립니다. 중간에 중단해도 다시 실행하면 이어집니다.

📘 **안내 문서 (PDF 로도 동봉)**
- `처음_설치_안내.pdf` — 준비물부터 첫 접속까지 전체 흐름
- `설치_체크리스트.pdf` — 하나씩 체크하며 진행
- `설치_중_막힐_때.pdf` — 증상별 해결
- `docs/운영자_가이드.md` — 설치 후 운영(역할·PIN·성원·광고)
- `docs/초기데이터_작성법.md` — 성원 명단을 CSV 로 한꺼번에 넣기
- `INSTALL.md` — 설치 도우미가 하는 일과 기술 상세(개발자·진행자용)

## 업데이트

새 버전이 나오면 배포본 폴더의 **`업데이트.cmd`**(Mac: `업데이트.command`)를 두 번 클릭합니다. 최신 파일을 내려받아 프로그램만 교체하고, 회중 데이터·PIN·설정(`web/dist/config.js`, `.secrets`, `.install`)은 그대로 둡니다. 화면이 열리면 **[다시 배포]** 한 번이면 끝입니다.

## 설치 도우미가 대신 하는 일

| 단계 | 자동 처리 |
|---|---|
| 실행환경 | 포터블 Node.js 와 배포 도구(wrangler, firebase-tools)를 첫 실행 때 내려받아 사용자 로컬 앱 폴더에 준비 |
| Google | Firebase 프로젝트 생성(또는 기존 선택), Firestore(서울) 생성, 웹 앱 등록, 설정값 6개 획득, 서비스 계정 키 생성 |
| Cloudflare | Worker 배포 + 서버 비밀 키 설정, Pages 프로젝트 생성·배포, 접속 검증 |
| 데이터 | 보안 규칙 배포, 집단·역할·광고 항목 초기 데이터 등록(이미 있으면 보존) |
| 화면 | 접속 주소·QR·기본 PIN 표, 설치 결과 파일 저장 |

사용자가 직접 하는 것은 회중 이름·집단 입력, Google/Cloudflare 로그인 클릭, Firebase 콘솔 "시작하기" 한 번뿐입니다.

## 기본 역할과 PIN

| 역할 | 기본 PIN |
|---|---|
| 회중 조정자 | `1111` |
| 회중 서기 | `2222` |
| 봉사 감독자 | `3333` |
| 생활과 봉사 감독자 | `4444` |
| 공개강연 조정자 | `5555` |
| 회중 장로 · 집단 감독자·보조자 | `0000` |

실제 사용 전에 반드시 바꾸세요. 편집자 로그인: 접속 주소 뒤에 `/?admin=1`.

## 주요 기능

- 온라인 봉사 보고 제출과 집단별 현황
- 성원별 개인 임명, 평일 집회 임명표, 주말 공개강연 사회·낭독·기도 임명
- 월 단위 개인 임명, 집단별 청소·봉사 임명
- 회중 광고, 지부 광고 서신, 우리 집단 소식
- 집단 편성표, 비상연락처·주소록, 출판물 신청 확인
- 집단 감독자·보조자 메뉴, 회중 역할자 권한별 편집 메뉴
- 홈 화면 하단 탭·전체 메뉴, PWA 설치

## 폴더 구성

```text
설치.cmd / 설치.command        설치 도우미 실행 (Windows / Mac)
업데이트.cmd / 업데이트.command  최신 배포본으로 업데이트 + 재배포
installer/                     설치 도우미(로컬 웹 화면·자동 프로비저닝)
web/dist/                      빌드된 웹 화면 (config.js 에 회중 설정이 들어감)
web/src/                       웹 화면 소스 (개발자용)
worker/                        PIN 로그인·서버 작업 Cloudflare Worker
scripts/                       초기 데이터 등록, 배포용 ZIP 만들기
templates/                     초기 데이터 CSV 틀
firestore.rules                데이터 보안 규칙
docs/                          운영자 가이드, 초기데이터 작성법 등
.install/  .secrets/           (설치 후 생김) 진행 상태·기록, 서버 키 — 공유 금지
```

## 개발자 참고

- 웹 화면 빌드: `cd web && npm install && npm run build` (배포본에는 빌드 결과 `web/dist` 를 동봉)
- 회중별 설정은 빌드가 아니라 `web/dist/config.js` 런타임 파일로 주입됩니다.
- 설치 도우미 점검 모드: `FSG_DEV=1` 환경변수로 서버를 실행하면 가짜 진행 버튼이 보입니다.
- 배포용 ZIP: `powershell -File scripts\make-zip.ps1`
- 저장소: https://github.com/allmightyrock-cpu/congregation-field-service-group-kit
- 설치 도우미 설계·실측 기록: `docs/설치도우미_재설계_계획.md`
