# Congregation Field Service Group Kit

회중 야외 봉사 집단 운영을 돕기 위한 웹 프로그램 배포본입니다.

성원은 자신의 집단 화면에서 온라인 봉사 보고, 임명 확인, 회중 광고, 집단 편성표를 확인할 수 있습니다. 집단감독자·보조자와 회중 역할자는 로그인 후 권한에 맞는 관리 메뉴를 사용할 수 있습니다.

## 주요 기능

- 온라인 봉사 보고 제출
- 집단별 보고 현황 확인
- 성원별 개인 임명 확인
- 평일 집회 임명표 확인
- 주말 공개강연 사회·낭독·기도 임명 확인
- 월 단위 개인 임명 확인
- 집단별 청소·봉사 관련 임명 확인
- 회중 광고, 지부 광고 서신, 우리 집단 소식 게시
- 집단 편성표 확인
- 집단감독자·보조자 전용 메뉴
- 회중 역할자 권한별 편집 메뉴
- 출판물 신청 확인
- 비상연락처·주소록 확인
- 동영상 자막 추출 보조 도구

## 처음 설치할 때 정하는 값

처음 설치할 때는 다음 값만 정하면 됩니다.

- 회중 이름
- 야외 봉사 집단 개수
- 각 집단 이름
- Firebase 프로젝트 정보
- Cloudflare Worker 이름
- Cloudflare Pages 이름

성원 이름은 처음 설치 때 넣지 않아도 됩니다. 설치 후 집단감독자·보조자가 직접 입력하거나, 회중 서기가 엑셀/CSV로 한꺼번에 정리할 수 있습니다.

## 기본 역할과 PIN

회중마다 공통으로 사용하는 역할은 기본값으로 준비되어 있습니다.

| 역할 | 기본 PIN |
|---|---|
| 조정자 | `1111` |
| 서기 | `2222` |
| 봉사감독자 | `3333` |
| 생활과봉사 감독자 | `4444` |
| 공개강연 조정자 | `5555` |
| 집단감독자·보조자 | `0000` |

실제 사용 전에는 반드시 PIN을 변경하세요.

## 설치 방법

설치 담당자 PC에는 먼저 Node.js가 필요합니다.

- 공식 사이트: https://nodejs.org/
- 권장 버전: LTS 버전
- Windows에서는 `Windows Installer (.msi)`를 내려받아 기본값으로 설치합니다.

Windows에서는 배포본 폴더에서 아래 파일을 실행합니다.

```text
쉬운설치.cmd
```

자세한 설치 안내는 [INSTALL.md](INSTALL.md)를 보세요.

## 업데이트 방법

GitHub 저장소로 설치한 경우에는 아래 파일을 실행해 최신 버전을 확인할 수 있습니다.

```text
업데이트확인.cmd
```

ZIP 파일로 설치한 경우에는 자동 업데이트가 제한됩니다. 최신 ZIP을 다시 내려받은 뒤, 기존 회중의 `web/.env`, `worker/wrangler.toml`, Firebase/Cloudflare 설정값을 보존해야 합니다.

## 자동 업데이트에 대한 안내

완전 자동 업데이트는 신중해야 합니다. 각 회중은 서로 다른 Firebase 데이터와 Cloudflare 설정을 사용하기 때문입니다.

권장 방식은 다음과 같습니다.

1. 프로그램 소스는 GitHub 저장소로 관리합니다.
2. 각 회중은 자신의 Firebase와 Cloudflare 설정을 유지합니다.
3. 업데이트가 나오면 GitHub에서 소스만 내려받습니다.
4. 데이터와 PIN, 회중 성원 정보는 덮어쓰지 않습니다.
5. 빌드와 배포를 다시 실행합니다.

이 방식이면 프로그램 기능과 디자인은 업데이트할 수 있고, 각 회중의 실제 데이터는 안전하게 보존됩니다.

## 폴더 구성

```text
web/        성원과 역할자가 접속하는 웹 화면
worker/     PIN 로그인과 서버 작업을 처리하는 Cloudflare Worker
shared/     웹과 Worker가 함께 쓰는 공통 로직
templates/  처음 설치할 때 사용하는 CSV 예시
scripts/    설치 도우미와 초기 데이터 등록 스크립트
docs/       설치와 운영 안내 문서
```
