# 감독자 로그인 안내

임명받은 감독자와 담당자는 편집자 화면에서 PIN으로 로그인합니다.

## 로그인 주소

```text
https://YOUR_PAGES_DOMAIN/admin.html
```

Cloudflare Pages 주소가 `example.pages.dev`라면 다음과 같습니다.

```text
https://example.pages.dev/admin.html
```

## 기본 역할 PIN

| 역할 | 기본 PIN |
| --- | --- |
| 회중 조정자 | 1111 |
| 회중 서기 | 2222 |
| 봉사 감독자 | 3333 |
| 생활과 봉사 감독자 | 4444 |
| 공개강연 조정자 | 5555 |

## 집단 감독자/보조자 PIN

설치 도우미에서 만든 각 집단에는 집단 감독자/보조자 로그인이 자동으로 만들어집니다.

기본 PIN은 모든 집단이 처음에는 다음과 같습니다.

```text
0000
```

설치 후 각 집단 감독자/보조자는 편집자 화면에 들어가 자기 PIN을 변경할 수 있습니다.

## 설치 후 반드시 할 일

1. 회중 역할 PIN `1111~5555`를 실제 PIN으로 변경합니다.
2. 집단 감독자/보조자 기본 PIN `0000`을 변경합니다.
3. PIN은 필요한 담당자에게만 전달합니다.
4. PIN을 공개 GitHub, 카페, 단체 채팅방에 올리지 않습니다.

## 성원 명단 입력

처음 설치 때는 성원 명단을 넣지 않아도 됩니다.

설치 후 다음 방식으로 입력합니다.

- 집단 감독자/보조자가 자기 집단 성원을 직접 추가
- 회중 서기가 전체 성원 명단을 정리해서 입력
- 추후 엑셀 가져오기 기능을 사용해 한꺼번에 정리

## 로그인 문제 해결

PIN 로그인이 되지 않으면 아래 내용을 확인하세요.

- 편집자 화면 주소가 맞는지 확인합니다.
- 선택한 역할 또는 집단이 맞는지 확인합니다.
- 기본 PIN을 변경했다면 새 PIN을 입력했는지 확인합니다.
- Worker의 `FIREBASE_SERVICE_ACCOUNT` secret이 설정되어 있는지 확인합니다.
- `web/.env`의 `VITE_WORKER_URL`이 실제 Worker 주소와 맞는지 확인합니다.
