# 회중 야외 봉사 집단 운영 프로그램 배포 안내

야외 봉사 집단 운영을 조금 더 편리하게 돕기 위한 웹 프로그램 배포본을 준비했습니다.

이 프로그램은 각 회중에서 지방적인 필요에 따라 설치해서 사용할 수 있도록 만든 배포 키트입니다.

[사진 삽입: 프로그램 메인 화면 또는 설치 도우미 화면]

## 어떤 프로그램인가요?

회중 야외 봉사 집단 운영에 필요한 여러 자료를 한곳에서 관리할 수 있도록 돕는 웹 프로그램입니다.

성원들은 휴대폰으로 자기 집단 화면에 접속할 수 있고, 임명받은 감독자나 담당자는 편집자 화면에서 필요한 자료를 관리할 수 있습니다.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 집단별 화면 | 각 집단별 성원과 안내 자료 확인 |
| 회중 광고 | 회중 전체에 필요한 광고와 안내 관리 |
| 지부 광고 서신 | 첨부 문서와 안내 자료 관리 |
| 집단 소식 | 특정 집단에만 필요한 소식 전달 |
| 집단 편성표 | 야외 봉사 집단 편성 자료 관리 |
| 봉사·청소 임명 | 월별 봉사와 청소 임명 관리 |
| 감독자 방문 | 봉사 감독자 방문 일정 안내 |
| 집회 임명표 | 평일 집회 임명표 관리 |
| 공개강연 안내 | 주말 공개강연 관련 정보 관리 |
| 역할별 PIN | 조정자, 서기, 봉사 감독자 등 역할별 관리 권한 분리 |

## 설치 방식

설치는 설치 담당자가 진행하는 것을 기준으로 합니다.

사용자는 복잡한 명령어를 입력하거나 프로그램 파일을 수정할 필요가 없습니다.

처음 설치하는 회중은 아래 값만 준비하면 됩니다.

## 설치 전에 준비할 값

| 준비 항목 | 설명 |
|---|---|
| 회중 이름 | 설치할 회중 이름 |
| 집단 개수 | 야외 봉사 집단 개수 |
| 집단 이름 | 각 집단의 지방적인 이름 |
| Firebase Project ID | Firebase에서 만든 프로젝트 ID |
| Firebase 웹 앱 설정값 | apiKey, authDomain, storageBucket, messagingSenderId, appId |
| Firebase 서비스 계정 JSON | Firebase에서 내려받는 비공개 JSON 파일 |
| Cloudflare 계정 | Cloudflare 로그인 계정 |
| 서버용 이름 | Cloudflare에서 사용할 영문 이름 |
| 웹사이트용 이름 | 최종 접속 주소에 들어갈 영문 이름 |

Firebase 콘솔 주소:

https://console.firebase.google.com/

1. Firebase 프로젝트 만들기
2. 웹 앱 설정값 5개 복사하기
3. 서비스 계정 JSON 파일 내려받기

설치 담당자에게 전달할 Firebase 값:

authDomain:

Firebase Project ID:

## 처음 설치할 때 성원 명단도 필요한가요?

필요하지 않습니다.

처음 설치할 때는 집단 개수와 집단 이름만 정하면 됩니다.

성원 이름은 설치 후에 입력할 수 있습니다.

1. 집단 감독자나 보조자가 직접 입력
2. 회중 서기가 엑셀 표로 한꺼번에 입력

## 기본 PIN 안내

처음 설치하면 아래 기본 PIN이 들어갑니다.

| 역할 | 기본 PIN |
|---|---|
| 회중 조정자 | 1111 |
| 회중 서기 | 2222 |
| 봉사 감독자 | 3333 |
| 생활과 봉사 감독자 | 4444 |
| 공개강연 조정자 | 5555 |
| 집단 감독자/보조자 | 0000 |

실제 사용 전에는 반드시 기본 PIN을 변경해야 합니다.

## 자주 묻는 질문

Q: 컴퓨터를 잘 모르는 사람도 설치할 수 있나요?

A: 사용자는 설치값만 준비하면 됩니다. 실제 설치와 배포는 설치 담당자가 진행하는 것을 기준으로 합니다.

Q: 성원 명단을 처음부터 모두 준비해야 하나요?

A: 아닙니다. 처음에는 집단 이름만 정하고, 성원 명단은 설치 후 입력할 수 있습니다.

Q: Firebase나 Cloudflare를 처음 사용해도 되나요?

A: 가능합니다. 안내문에는 어디에 접속해서 어떤 값을 복사해야 하는지만 정리되어 있습니다.

Q: 서비스 계정 JSON 파일을 카페에 첨부해도 되나요?

A: 안 됩니다. 이 파일은 비공개 키이므로 설치 담당자에게만 직접 전달해야 합니다.

Q: 설치 후 PIN은 그대로 사용해도 되나요?

A: 실제 사용 전에는 반드시 기본 PIN을 변경해야 합니다.
