# 회중 야외 봉사 집단 프로그램 배포 안내

회중 야외 봉사 집단 운영을 돕는 웹 프로그램 배포본입니다. 각 회중은 자기 회중 이름과 집단 이름을 설정해서 사용할 수 있습니다.

## 어떤 기능이 있나요?

- 성원 온라인 봉사 보고 제출
- 집단별 보고 제출 현황 확인
- 집단감독자/보조자용 자기 집단 보고 기록 확인
- 서기, 조정자, 봉사감독자용 회중 전체 보고 현황 확인
- 평일 집회 임명 확인
- 주말 성서공개강연 사회, 낭독, 기도 임명 확인
- 주차, 안내, 연사 음료 등 월 단위 개인 임명 확인
- 집단별 청소 임명 확인
- 회중 광고, 지부 서신, 집단 소식 게시
- 집단 편성표와 성원 관리
- 보조 도구: 동영상 자막 추출

## 설치 방식

설치 담당자는 배포본 ZIP 파일을 내려받은 뒤 Windows에서 `쉬운설치.cmd`를 실행합니다.

설치 담당자 PC에는 먼저 Node.js가 필요합니다. Node.js 공식 사이트에서 LTS 버전의 Windows Installer(.msi)를 내려받아 기본값으로 설치하면 됩니다.

Node.js 공식 사이트:

https://nodejs.org/

설치 도우미는 다음 정보를 차례대로 입력받습니다.

- 회중 이름
- 집단 개수와 집단 이름
- Firebase 설정값
- Firebase 서비스 계정 JSON
- Cloudflare Worker 이름
- Cloudflare Pages 이름

처음 설치 때 성원 이름은 입력하지 않아도 됩니다. 설치 후 집단감독자/보조자가 직접 입력하거나, 서기가 엑셀 자료로 정리해서 일괄 입력할 수 있습니다.

## 기본 PIN

- 회중 조정자: `1111`
- 서기: `2222`
- 봉사감독자: `3333`
- 생활과 봉사 감독자: `4444`
- 공개강연 조정자: `5555`
- 집단감독자/보조자: `0000`

설치 후 실제 사용 전에는 반드시 PIN을 변경해야 합니다.

## 배포 파일

- GitHub 저장소: 설치 파일과 소스 확인용
- ZIP 파일: 처음 설치하는 회중이 내려받아 실행하기 쉬운 배포본
