# [업데이트] 야외 봉사 집단 앱 — 설치 도우미가 새로 바뀌었습니다 (설치가 훨씬 쉬워졌어요)

안녕하세요. 회중 야외 봉사 집단 앱 배포본이 **2026.09.07 버전**으로 올라왔습니다.
그동안 "설치가 어렵다", "중간에 막힌다"는 말씀을 많이 주셨는데, 이번에 **설치 방식 자체를 다시 만들었습니다.**

## 무엇이 달라졌나요

**1. 미리 설치할 프로그램이 없습니다**
예전엔 Node.js 를 먼저 깔아야 했는데, 이제 필요 없습니다. 설치 파일을 두 번 클릭하면 필요한 것을 알아서 내려받습니다(첫 실행 때 2~5분).

**2. 설치 파일 하나로 끝납니다 — Windows·Mac 모두**
`설치.cmd`(Windows) 또는 `설치.command`(Mac)를 두 번 클릭하면 브라우저에 **설치 도우미 화면**이 열리고, 한 화면에 한 가지씩 안내합니다.

**3. 복사해 붙여 넣을 값이 없습니다**
Firebase 설정값 6개, 서비스 계정 파일, 서버 주소… 이제 직접 찾을 필요가 없습니다. **Google 로그인 한 번, Cloudflare 로그인 한 번**이면 도우미가 프로젝트·저장소·서버 키·서버 주소를 전부 자동으로 만들고 연결합니다.
직접 입력하는 것은 **회중 이름과 집단 수·이름**뿐입니다.

**4. 중간에 멈춰도 이어서 됩니다**
창을 닫았다가 다시 열어도 저장된 단계에서 이어갑니다. 문제가 생기면 화면에 **한국어로 원인과 해결 방법**이 나오고 [다시 시도] 버튼이 있습니다.

**5. 감독자 로그인이 안 되던 문제를 고쳤습니다**
예전 도우미로 설치하면 서버 비밀 키가 설정되지 않아 로그인이 안 되는 경우가 있었습니다. 이번 도우미는 배포와 함께 자동으로 설정합니다. 그 밖에 규칙 배포 실패(파일 인코딩), 편집자 화면 집단 순서 문제도 함께 고쳤습니다.

**6. 업데이트도 한 번에**
앞으로 새 버전이 나오면 배포본 폴더의 `업데이트.cmd` 를 두 번 클릭하고 [다시 배포]만 누르면 됩니다. 회중 데이터·PIN·설정은 그대로 유지됩니다.

## 설치 순서 (약 10~15분)

1. 아래 링크에서 배포본 ZIP 을 받아 `문서` 폴더 등에 압축을 풉니다.
2. `설치.cmd`(Mac: `설치.command`)를 두 번 클릭합니다.
   - Windows 에서 파란 "PC 보호" 창이 뜨면 **추가 정보 → 실행**, Mac 에서 경고가 뜨면 **우클릭 → 열기**.
3. 브라우저에 열린 도우미 화면을 따라갑니다: 회중 정보 입력 → Google 로그인 → (Firebase 페이지에서 **시작하기** 한 번 클릭) → Cloudflare 로그인 → [설치 시작].
4. 완료 화면의 **접속 주소와 QR** 을 성원에게 공유하고, 편집자 로그인(주소 뒤에 `/?admin=1`) 후 **기본 PIN 을 꼭 바꿔 주세요.**

준비물은 인터넷이 되는 컴퓨터, 회중용 Google 계정, Cloudflare 계정(무료, 이메일로 가입) 세 가지입니다.

## 이미 예전 방식으로 설치한 회중은

새 배포본을 받아 `설치.cmd` 를 실행하고, Google 단계에서 **"기존 프로젝트 사용"** 을 골라 지금 쓰는 Firebase 프로젝트를 선택하면 데이터가 그대로 보존됩니다. Cloudflare 이름을 기존 Worker·사이트 이름과 같게 맞추면 접속 주소도 유지됩니다. 자세한 내용은 배포본 안 `docs/배포본_변경사항_2026-09.md` 를 보세요.

## 막히면

`설치_중_막힐_때.pdf` 에 증상별 해결 방법이 있습니다. 그래도 안 되면 도우미 화면 아래 **"자세한 기록" → [기록 복사]** 를 눌러 복사된 내용을 댓글이나 쪽지로 보내 주세요. 기록에서 키·비밀번호는 자동으로 가려집니다.

설치하시면서 불편한 점이나 헷갈리는 화면이 있으면 알려 주세요. 다음 업데이트에 반영하겠습니다.
