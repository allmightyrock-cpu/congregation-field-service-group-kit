# 배포본 변경사항 2026-08

이 배포본은 최근 운영본에서 검증한 화면 구성과 권한 흐름을 바탕으로 정리한 타 회중 설치용 배포본입니다.

## 주요 변경

- 현재 운영본 디자인 반영
- 상단 메뉴와 상세 메뉴 연결 방식 정리
- 회중 광고, 집단 편성표 등 주요 카드의 직접 연결 개선
- 회중 역할자 로그인과 집단감독자·보조자 로그인 흐름 정리
- 로그인 후 권한별 편집 메뉴 표시
- 보고 현황 권한 기준 정리
- 출판물 신청, 비상연락처·주소록 메뉴 포함
- 온라인 봉사 보고 기능 유지
- 성원별 임명 확인 기능 유지
- 동영상 자막 추출 보조 도구 포함
- README와 INSTALL 문서 한글 재정리
- 업데이트 확인 스크립트 추가

## 배포 기준

이 배포본은 특정 회중의 실제 데이터나 PIN을 포함하지 않습니다.

각 회중은 설치 도우미에서 다음 값을 직접 정합니다.

- 회중 이름
- 집단 개수와 집단 이름
- Firebase 프로젝트
- Cloudflare Worker/Pages 이름

## 업데이트 기준

프로그램 소스 업데이트와 회중 데이터는 분리해서 관리합니다.

- 업데이트 대상: 웹 화면, Worker 기능, 공통 로직, 문서
- 보존 대상: Firebase 데이터, 성원 명단, 실제 PIN, 환경 설정값

GitHub 저장소로 설치한 경우에는 `업데이트확인.cmd`를 사용할 수 있습니다.
