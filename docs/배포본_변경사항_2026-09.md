# 배포본 변경사항 (2026-09) — 설치 도우미 v2

버전: `2026.09.07-installer-v2`

## 설치 방식이 바뀌었습니다

| 이전 | 지금 |
|---|---|
| Node.js 를 먼저 설치해야 함 | 필요 없음. 첫 실행 때 포터블 실행환경을 자동으로 내려받음 |
| `쉬운설치.cmd` (Windows 전용 창) | `설치.cmd` / `설치.command` (Windows·Mac), 브라우저 화면 |
| Firebase 설정값 6개 + 서비스 계정 파일을 직접 복사·입력 | Google 로그인만 하면 프로젝트·설정값·키를 자동으로 준비 |
| Worker 주소를 미리 알아야 함 | 배포하면서 자동으로 얻어 설정에 넣음 |
| 서버 비밀 키(FIREBASE_SERVICE_ACCOUNT)가 설정되지 않아 감독자 로그인 불가 | 배포와 함께 자동 설정(핵심 결함 수정) |
| 오류가 영어로만 나오고 재실행 불가 | 한국어 원인·조치 표시, 중단해도 이어하기 |
| 설치 PC 에서 빌드(npm install ×2, vite build) | 빌드본 동봉, 회중별 설정은 `web/dist/config.js` 런타임 파일 |
| 업데이트 시 재설정·재빌드 | `업데이트.cmd` → 파일 교체 후 [다시 배포] 한 번 |

## 함께 고친 것
- `firestore.rules` 파일 선두 BOM 으로 규칙 배포가 실패하던 문제
- 편집자 화면의 집단 순서가 특정 회중 키로 고정되어 있던 문제 → Firestore 집단 목록을 따름
- 홈 화면 재설계(하단 탭·전체 메뉴), PWA 설치, 디자이너 아이콘, 공개강연 행사 스타일

## 제거된 파일
`쉬운설치.cmd`, `업데이트확인.cmd`, `scripts/install-helper-gui.ps1`, `scripts/easy-install.ps1`, `scripts/install-helper-ko.json`, `scripts/update-from-github.ps1`, 옛 안내 문서 일부. 대신 `설치.cmd`, `업데이트.cmd`, `installer/` 폴더가 들어갑니다.

## 이미 설치한 회중이 새 버전으로 옮기려면
1. 새 배포본 ZIP 을 기존 폴더 위에 덮어씁니다(또는 새 폴더에 풉니다).
2. `설치.cmd` 를 실행해 도우미를 진행합니다. 3단계에서 **기존 프로젝트 사용**을 고르고 기존 Firebase 프로젝트를 선택하면 데이터가 보존됩니다. Cloudflare 이름은 기존 Worker/Pages 이름과 같게 맞추면 주소가 유지됩니다.
3. 초기 데이터 등록은 이미 초기화된 프로젝트에서는 자동으로 건너뜁니다(PIN·성원 보존).
