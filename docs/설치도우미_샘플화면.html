Firebase 콘솔에서 프로젝트 설정 > 일반 > 내 앱 > 웹 앱 > Config 화면을 엽니다. 아래 5개 값만 복사합니다.

처음이면 여기부터

https://console.firebase.google.com/
1구글에서 Firebase 콘솔 또는 Firebase console을 검색해도 됩니다.
2프로젝트 추가를 누르고 Firestore Database를 만듭니다.
3프로젝트 설정의 일반 탭에서 웹 앱을 추가합니다.
4Config 코드에 있는 `apiKey`, `projectId`, `appId` 등의 값을 복사합니다.
5서비스 계정 탭에서 비공개 키 JSON 파일을 내려받아 기본 정보 화면에 선택합니다.
서비스 계정 JSON은 비밀번호처럼 다룹니다. GitHub나 카페 글에 첨부하지 않습니다.
