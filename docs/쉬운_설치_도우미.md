# 쉬운 설치 도우미 안내

이 배포본에는 Windows 사용자를 위한 쉬운 설치 도우미가 포함되어 있습니다.
기본 실행 파일은 화면형 설치 도우미를 엽니다.

## 실행 파일

배포본 폴더에서 아래 파일을 더블 클릭합니다.

```text
쉬운설치.cmd
```

또는 PowerShell에서 직접 실행할 수 있습니다.

```powershell
powershell -ExecutionPolicy Bypass -File scripts/easy-install.ps1
```

이 명령도 같은 화면형 설치 도우미를 엽니다.

샘플 화면은 아래 파일에서 먼저 확인할 수 있습니다.

```text
docs/설치도우미_샘플화면.html
```

Firebase와 Cloudflare 값을 어디서 찾는지 자세한 설명은 아래 문서를 참고하세요.

```text
docs/Firebase_Cloudflare_설정_상세안내.md
```

## 설치 도우미가 해 주는 일

- 단계별 입력 화면 제공
- Node.js, npm, npx 설치 여부 확인
- Firebase 웹 앱 설정값을 받아 `web/.env` 자동 생성
- `worker/wrangler.toml`의 Worker 이름과 Firebase Project ID 자동 수정
- 초기 CSV 자료 확인 시간 제공
- 웹/Worker 의존성 설치
- 처음에는 집단 개수와 이름만 받아 기본 자료 생성
- 성원 명단은 비워 두고, 설치 후 감독자/보조자 또는 서기가 입력
- `templates/*.csv` 자료를 Firestore에 등록
- Firebase 규칙과 인덱스 배포
- Cloudflare Worker secret 등록
- Cloudflare Worker 배포
- 웹 앱 빌드
- Cloudflare Pages 배포

## 설치 전에 준비할 것

아래 자료는 설치 도우미가 대신 만들 수 없으므로 미리 준비해야 합니다.

- Firebase 계정
- Firebase Project ID
- Firebase 웹 앱 설정값
- Firebase 서비스 계정 JSON 파일
- Cloudflare 계정
- 회중 야외 봉사 집단 개수와 이름

## Firebase 웹 앱 설정값 찾는 곳

Firebase 콘솔에서 해당 프로젝트를 열고 `프로젝트 설정 > 일반 > 내 앱 > 웹 앱`으로 들어가면 아래 값들을 확인할 수 있습니다.

- `apiKey`
- `authDomain`
- `projectId`
- `storageBucket`
- `messagingSenderId`
- `appId`

설치 도우미에는 각각 아래 이름으로 입력합니다.

- `VITE_FIREBASE_API_KEY`
- `VITE_FIREBASE_AUTH_DOMAIN`
- `VITE_FIREBASE_STORAGE_BUCKET`
- `VITE_FIREBASE_MESSAGING_SENDER_ID`
- `VITE_FIREBASE_APP_ID`

## 서비스 계정 JSON 준비

Firebase 콘솔에서 `프로젝트 설정 > 서비스 계정 > 새 비공개 키 생성`을 눌러 JSON 파일을 내려받습니다.

이 파일은 공개 저장소, 카페, 단체 채팅방에 올리면 안 됩니다. 설치하는 컴퓨터 안에만 보관하세요.

## CSV 수정

설치 도우미는 집단 개수와 이름을 바탕으로 CSV를 먼저 만들어 줍니다.

- `templates/groups.csv`: 집단 이름
- `templates/members.csv`: 처음에는 비어 있음
- `templates/roles.csv`: 고정 역할과 기본 PIN
- `templates/notices.csv`: 광고 메뉴

기본 PIN:

- 회중 조정자: `1111`
- 회중 서기: `2222`
- 봉사 감독자: `3333`
- 생활과 봉사 감독자: `4444`
- 공개강연 조정자: `5555`
- 집단 감독자/보조자: `0000`

실제 사용 전에는 기본 PIN을 반드시 바꾸세요.

## 중간에 실패했을 때

설치 도우미는 실패한 단계에서 멈춥니다. 오류 내용을 확인한 뒤 같은 파일을 다시 실행하면 됩니다.

자주 생기는 문제:

- Node.js가 설치되어 있지 않음
- Firebase 서비스 계정 JSON 경로가 잘못됨
- Firebase Project ID가 다름
- Cloudflare 로그인이 되어 있지 않음
- Worker URL을 `web/.env`에 잘못 입력함

## 완전 자동 설치가 어려운 이유

Firebase와 Cloudflare는 각 회중의 계정 권한으로 로그인하고 승인해야 합니다. 그래서 계정 생성과 로그인 승인까지 프로그램이 몰래 처리할 수는 없습니다.

대신 이 설치 도우미는 사용자가 직접 승인해야 하는 부분을 제외하고, 반복되는 명령어와 파일 수정을 최대한 자동으로 처리합니다.
