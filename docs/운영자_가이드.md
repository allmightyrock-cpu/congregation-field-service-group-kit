# 운영자 가이드

## 운영 원칙

- 실제 성원 명단과 PIN은 필요한 사람에게만 공유합니다.
- GitHub 공개 저장소에는 예제 데이터만 올립니다.
- 서비스 계정 JSON, `.env`, 실제 CSV 백업 파일은 저장소 밖에 보관합니다.
- PIN은 설치 후 즉시 변경하고, 담당자가 바뀌면 다시 변경합니다.

## 감독자 로그인

임명받은 감독자와 담당자는 `admin.html` 편집자 화면에서 PIN으로 로그인합니다. 기본 역할과 PIN은 `templates/roles.csv`에서 설정하며, 설치 후 반드시 회중 상황에 맞게 변경합니다.

자세한 안내는 [감독자_로그인_안내.md](감독자_로그인_안내.md)를 참고하세요.

## 광고 관리

회중 전체에 필요한 내용은 `회중 광고`에 올리고, 집단별 전달 사항은 `우리 집단 소식`에 올립니다. 긴급 광고는 실제 긴급 안내가 있을 때만 표시하고, 종료된 광고는 바로 숨김 처리합니다.

## 성원 명단 관리

성원이 이동하거나 새로 들어오면 편집자 화면에서 명단을 수정합니다. 초기 설치 때처럼 CSV를 다시 가져오는 방식도 가능하지만, 운영 중에는 화면에서 직접 수정하는 편이 안전합니다.

## 보고 기간

보고 기간은 기본적으로 날짜에 따라 자동 계산됩니다. 회중 운영상 별도 기간이 필요할 때는 `config/app` 문서의 `reportPeriodOverride` 값을 `YYYY-MM` 형식으로 지정할 수 있습니다.

## 백업

정기적으로 Firestore 데이터를 내보내거나, 최소한 `groups`, `roles`, `notices`, `config` 자료를 별도 백업하세요. 백업 파일에는 개인정보가 들어갈 수 있으므로 공개 저장소에 올리지 않습니다.
