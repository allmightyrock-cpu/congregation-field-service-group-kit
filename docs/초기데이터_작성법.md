# 초기 데이터 작성법

처음 설치할 때는 모든 성원 명단을 준비하지 않아도 됩니다. 먼저 회중 야외 봉사 집단의 **개수와 이름**만 정하고 설치를 시작합니다.

성원 명단은 설치 후 편집자 화면에서 집단 감독자/보조자가 직접 입력하거나, 회중 서기가 엑셀 자료를 정리해서 한꺼번에 가져오는 방식으로 운영합니다.

## groups.csv

집단 목록입니다. 설치 도우미가 집단 개수와 이름을 받아 자동으로 만듭니다.

```csv
key,name,overseerName,assistantName,active,sortOrder
group1,1집단,,,true,1
group2,2집단,,,true,2
group3,3집단,,,true,3
```

- `key`: 시스템에서 쓰는 집단 고유값입니다. 예: `group1`
- `name`: 화면에 보이는 집단명입니다.
- `overseerName`: 집단 감독자 이름입니다. 처음에는 비워 둘 수 있습니다.
- `assistantName`: 보조자 이름입니다. 처음에는 비워 둘 수 있습니다.
- `active`: 사용 여부입니다.
- `sortOrder`: 표시 순서입니다.

## members.csv

처음 설치 때는 비워 둡니다.

```csv
groupKey,seq,name,displayName,gender,role,regularPioneer,active,note
```

설치 후 편집자 화면에서 성원을 추가할 수 있습니다.

## roles.csv

회중마다 공통으로 필요한 역할은 기본값으로 들어 있습니다.

| 역할 | 기본 PIN |
| --- | --- |
| 회중 조정자 | 1111 |
| 회중 서기 | 2222 |
| 봉사 감독자 | 3333 |
| 생활과 봉사 감독자 | 4444 |
| 공개강연 조정자 | 5555 |
| 회중 장로 | 0000 |

집단 감독자/보조자 로그인은 각 집단마다 자동으로 만들어지며 기본 PIN은 `0000`입니다.

실제 사용 전에는 기본 PIN을 반드시 변경하세요.

## notices.csv

광고와 안내 메뉴입니다. 기본값을 그대로 사용해도 됩니다.

```csv
key,title,subtitle,order,visible,urgent
cong,회중 광고,회중 전체에 내려온 안내,10,true,false
```

필요하면 제목과 설명만 회중 상황에 맞게 바꿀 수 있습니다.
