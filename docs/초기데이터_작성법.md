# 초기 데이터 작성법

`templates/` 폴더의 CSV 파일을 수정한 뒤 `scripts/setup-from-csv.mjs`를 실행하면 Firestore에 기본 자료가 등록됩니다.

## groups.csv

집단 목록입니다.

```csv
key,name,overseerName,assistantName,active,sortOrder
group1,1집단,홍길동,김사랑,true,1
```

- `key`: 주소와 권한에 쓰이는 고유값입니다. 예: `group1`
- `name`: 화면에 보이는 집단명입니다.
- `overseerName`: 집단 감독자 이름입니다.
- `assistantName`: 보조자 이름입니다.
- `active`: 사용 여부입니다. `true` 또는 `false`
- `sortOrder`: 표시 순서입니다.

## members.csv

성원 명단입니다.

```csv
groupKey,seq,name,displayName,gender,role,regularPioneer,active,note
group1,1,홍길동,홍길동,형제,감독자,false,true,
```

- `groupKey`: `groups.csv`의 `key`와 같아야 합니다.
- `seq`: 집단 안에서의 순서입니다.
- `name`: 실제 저장 이름입니다.
- `displayName`: 화면 표시 이름입니다. 비워 두면 `name`이 사용됩니다.
- `gender`: 형제, 자매 등 필요한 구분을 적습니다.
- `role`: 감독자, 보조자, 성원 등입니다.
- `regularPioneer`: 정규 파이오니아 여부입니다.
- `active`: 현재 사용 여부입니다.
- `note`: 비공개 메모입니다. 필요 없으면 비워 둡니다.

## roles.csv

편집자 권한과 PIN입니다.

```csv
key,name,pin,kind,groupKeys,noticeKeys,canReadCongReports,canWriteCongMembers,canManagePublications,canReadContacts,canWriteContacts
secretary,서기,2468,editor,*,cong|branch|week|groupnews|duty|visit|mid|talk|roster,true,true,true,true,true
```

- `key`: 역할 고유값입니다.
- `name`: 화면에 표시될 역할 이름입니다.
- `pin`: 로그인 PIN입니다. 설치 후 반드시 바꾸세요.
- `groupKeys`: 관리 가능한 집단입니다. 전체 권한은 `*`, 여러 개는 `group1|group2`처럼 씁니다.
- `noticeKeys`: 관리 가능한 광고 메뉴입니다. 여러 개는 `|`로 구분합니다.
- `canReadCongReports`: 전체 보고 집계 열람 권한입니다.
- `canWriteCongMembers`: 성원 명단 수정 권한입니다.
- `canManagePublications`: 출판물 배부 관리 권한입니다.
- `canReadContacts`: 연락처 열람 권한입니다.
- `canWriteContacts`: 연락처 수정 권한입니다.

## notices.csv

광고와 안내 메뉴입니다.

```csv
key,title,subtitle,order,visible,urgent
cong,회중 광고,회중 전체에 내려온 안내,10,true,false
```

- `key`: 메뉴 고유값입니다.
- `title`: 메뉴 제목입니다.
- `subtitle`: 짧은 설명입니다.
- `order`: 표시 순서입니다.
- `visible`: 화면 표시 여부입니다.
- `urgent`: 긴급 광고 표시 여부입니다.
