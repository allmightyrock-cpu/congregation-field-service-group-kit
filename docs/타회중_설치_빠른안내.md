# 타 회중 설치 빠른 안내

이 안내는 처음 설치하는 분이 Firebase와 Cloudflare를 처음 사용한다고 가정하고 작성한 요약입니다. 자세한 기술 설명은 `INSTALL.md`와 `docs/Firebase_Cloudflare_설정_상세안내.md`를 함께 보세요.

## 1. 먼저 준비할 것

- 회중 이름
- 야외 봉사 집단 개수
- 각 집단 이름
- Firebase 프로젝트
- Firebase 웹 앱 설정값
- Firebase 서비스 계정 JSON 파일
- Cloudflare 계정
- Cloudflare Worker 이름
- Cloudflare Pages 프로젝트 이름

처음 설치 때 성원 이름은 필요하지 않습니다.

## 2. 설치 도우미 실행

설치 담당자 PC에 Node.js가 없다면 먼저 설치합니다.

- 공식 사이트: https://nodejs.org/
- 받을 파일: LTS 버전의 Windows Installer(.msi)
- 설치 방법: 기본값으로 계속 진행

Windows에서 배포본 폴더를 열고 아래 파일을 실행합니다.

```text
쉬운설치.cmd
```

설치 도우미 화면에서 차례대로 입력합니다.

1. 회중 이름과 Firebase Project ID를 입력합니다.
2. Firebase 서비스 계정 JSON 파일을 선택합니다.
3. 집단 개수와 집단 이름을 입력합니다.
4. Firebase 웹 앱 설정값을 붙여 넣습니다.
5. Cloudflare Worker 이름과 Pages 이름을 입력합니다.
6. 준비 파일 만들기 또는 배포 실행을 선택합니다.

## 3. 기본 PIN

처음 설치 후 기본 PIN은 아래와 같습니다.

| 역할 | 기본 PIN |
|---|---|
| 회중 조정자 | `1111` |
| 서기 | `2222` |
| 봉사감독자 | `3333` |
| 생활과 봉사 감독자 | `4444` |
| 공개강연 조정자 | `5555` |
| 모든 집단감독자/보조자 | `0000` |

실제 사용 전에는 반드시 PIN을 변경하세요.

## 4. 설치 후 전달할 주소

설치가 끝나면 아래 주소를 회중 상황에 맞게 전달합니다.

- 전체 집단 목록: `https://YOUR_PAGES_DOMAIN/`
- 집단별 성원 화면: `https://YOUR_PAGES_DOMAIN/?g=group1`
- 감독자 로그인: 각 집단 화면 오른쪽 위 `감독자 로그인`
- 회중 역할자 로그인: 상단 메뉴 `편집자 > 회중 역할자 로그인`

## 5. 주의

Firebase 서비스 계정 JSON, `.env` 파일, 실제 성원 명단, 실제 PIN은 공개 GitHub나 네이버 카페에 올리지 마세요.
